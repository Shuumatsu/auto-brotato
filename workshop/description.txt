[b]AutoBattler — movement autopilot for Brotato[/b]

The character moves and dodges by itself during waves. [b]Every decision stays yours[/b]: level-up picks, shop buys/rerolls/locks, crates/consumables, "next wave", character/weapon/danger selection.

[b]Controls[/b]
[list]
[*]Shift+Space — toggle the autopilot at any time (top-left HUD shows AUTOPILOT: ON/OFF)
[*]It is ON by default; state is saved between sessions.
[/list]

[b]What it does[/b]
[list]
[*]Dodges bullets, chargers, AoE telegraphs, spawn markers
[*]Kites at weapon range, collects materials/food/trees, avoids walls/corners
[*]Planning (v2.5.0): predicts an incoming encirclement and breaks out BEFORE the ring closes; commits to high-value pickups it would otherwise pass (DLC evolution fruits, hurt fruit, trees), including the ones that are lost at the wave horn
[*]Contact fix (v2.6.1): the bot no longer drifts into a monster and orbits it in otherwise calm, sparse waves (chasing bodies are now projected as pursuers in the crowding terms instead of being extrapolated through you); a winding-up charger's frozen body is priced; elite/boss/DLC non-circle contact hitboxes can no longer be under-estimated. Opt-outs: --arb-roomtrack / --arb-windup / --arb-hitbox
[*]Space & special targets (v2.6.0): retreats from the wall band before a crowd squeezes it shut and resists drifting to the edge; approaches special targets (bosses/elites, spawner eggs, cursed/evolved) when it is safe, prices item crates as items and loot aliens as worth a detour
[*]DLC-aware (v2.4.0): engages cursed enemies (Abyssal Terrors) and evolved meca/mutant enemies (Primal Dread) by default, and walks over the Primal Dread evolution consumables (meca/mutant fruit, mutation fruit, meca parts). Both stances are adjustable — use a negative `--arb-curse` / `--arb-evolved` value to avoid them instead.
[*]Behaviour priors are inferred from the build at runtime (HP/armor/dodge, lifesteal, "fire while moving", structures, economy mechanics) instead of a per-character lookup table
[*]No shop or upgrade script extensions are installed — decisions are structurally untouched
[/list]

[b]Install (Steam)[/b]
Subscribe, then start the game through Steam. ModLoader will load it from the Workshop folder. It needs nothing else (no ContentLoader, no Mod Options).

[b]Notes / limits[/b]
[list]
[*]Tested on Brotato 1.2.0.1. Updates may break it; unsubscribing restores vanilla.
[*]Single-player oriented; co-op not verified.
[*]Not affiliated with Blobfish or the original BOTato author.
[/list]

[b]中文说明[/b]

角色在波次内自动走位、闪避、砍树、受伤后吃果子、捡材料；[b]所有决策仍然由你来做[/b]：升级三选一、商店购买/刷新/锁定、开箱/消耗品、点"下一波"、角色/武器/难度选择。

v2.6.1 贴身/碰撞修复：不再“场上没几只怪却贴着怪打转”——拥挤项改为追击投影（逃跑不再被算成更拥挤）；蓄力定身怪补上接触价；精英/Boss/DLC 非圆形碰撞体的接触距离不再低估。开关：--arb-roomtrack / --arb-windup / --arb-hitbox，全 0 可回退。
v2.6.0 空间规划/特殊目标：不会被一点点挤到地图边缘（贴墙带提前撤离 + open-floor 势场），会主动接近精英/Boss、生成器蛋、诅咒/进化怪等特殊目标，物品箱按“一个物品”定价、逃跑掉落怪值得追。开关：--arb-space / --arb-bounty / --arb-boxes，全 0 可回退。

v2.5.0 规划能力：会预测“马上要被包围”（按追击者会转向、1.8s 后的合围空缺）并在环合上之前主动突围；会给高价值物品（DLC 进化果/受伤果子/树）做目标承诺，而不是只吃路过的；修好了“走到进化物品旁却不捡/停在圈边不消费”的拾取语义，并给波末会消失的机械/异变果实加拾取紧迫度。开关：--arb-breakout / --arb-goal / --arb-pursuit / --arb-walk / --arb-waveend，全 0 精确回到 2.4.0 行为。

v2.4.0 DLC 适配：默认主动交战诅咒怪（DLC1）和机械/异变进化怪（DLC2），并主动走过去捡新 DLC 的进化物品（机械果实/异变果/异变基因/机械部件）；不想打的时候用负数开关（如 --arb-curse=-1）进入回避姿态。开关全 0 可精确回到 2.3.0 行为。

v2.3.0 策略升级：远程 build 保持在射程边缘风筝而不是贴脸；静场会去砍树、掉血会去吃果子；每帧不再是单步贪心，而是 2 步前瞻规划；受击后 2 秒内临时提高警戒。所有新行为都有精确回退开关。

控制：Shift+Space 随时开关（默认开启，左上角 HUD 显示状态，开关会保存）。

本 Mod 只装了"走位"相关的两个最小扩展，不装任何商店/升级扩展；角色行为参数从实时 build 数据（血量/护甲/闪避、吸血、能否移动射击、结构物、经济机制等）自动推导，不再依赖逐角色手写表。

已在 Brotato 1.2.0.1 单机实测（第 1 波）。联机未验证；游戏更新可能失效，退订即恢复原版。

致谢：走位 AI 来自开源项目 BOTato（MIT，作者 boardengineer / Pasha），许可文件随 zip 附带。

[*]2.3.0 — smarter movement: ranged standoff/kiting, tree-felling and hurt-fruit opportunity terms, 2-ply lookahead planner, hit-adaptive caution; all with exact opt-out flags (--arb-kite / --arb-tree / --arb-food / --arb-plan / --arb-adapt).
