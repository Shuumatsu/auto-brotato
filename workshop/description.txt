[b]AutoBattler — movement autopilot for Brotato[/b]

The character moves and dodges by itself during waves. [b]Every decision stays yours[/b]: level-up picks, shop buys/rerolls/locks, crates/consumables, "next wave", character/weapon/danger selection.

[b]Controls[/b]
[list]
[*]Shift+Space — toggle the autopilot at any time (top-left HUD shows AUTOPILOT: ON/OFF)
[*]ON by default; state is saved between sessions.
[/list]

[b]What it does[/b]
[list]
[*]Contact fix #2 (v2.10.0, seventh play-test): objective pulls (the committed goal/bounty pull and the per-step reward attraction) are damped to zero while any contact/dash body is inside its taper band, so a committed resource behind a monster no longer makes the bot walk through it; the wave-end deadline is applied ONCE (econ_planner is the single owner) instead of twice, so end-of-wave tree / lost-at-horn fruit sweeps are no longer over-valued up to 9x. Opt-outs: --arb-pullsafe (0 = exact v2.9.1), --arb-econdl (1 = v2.9.1 double scaling).
[*]Dodges bullets, chargers, AoE telegraphs, spawn markers
[*]High-value coverage + live CD sync (v2.8.0): Boss/Elite priced apart (50 / 30) and produces get explicit values -- crate 20, legendary 34, evolution item 20, loot alien 12, tree 7 (reward tag index 6, max(raw, table); healing fruit keeps raw food); fire_still tap-move stops ONE frame when a weapon is ready (live cooldown sync) instead of fixed 2+2. Opt-outs: --arb-cov / --arb-tapcd (0 = exact v2.7.0); --arb-dpsref=2 opt-in killability
[*]Unified opportunity planning (v2.7.0): one value-vs-route-risk planner replaces the v2.6 bounty/goal gates -- explicit special-target values (boss/elite 30, spawner egg 40, cursed/evolved 18), detours priced against expected route damage; special targets gathered to 900/1400/1600 px by --arb-agg; fleeing loot aliens intercepted via measured velocity. Opt-outs: --arb-opp (0 = exact v2.6.1) / --arb-agg
[*]Kites at weapon range, collects materials/food/trees, avoids walls/corners
[*]Planning (v2.5.0): breaks out of an encirclement BEFORE the ring closes and commits to high-value pickups it would otherwise pass (DLC evolution fruits, hurt fruit, trees), incl. ones lost at the wave horn
[*]Contact fix (v2.6.1): no longer drifts into a monster and orbits it in calm, sparse waves (chasing bodies are projected as pursuers in the crowding terms, not extrapolated through you); winding-up charger bodies are priced; elite/boss/DLC non-circle hitboxes are never under-estimated. Opt-outs: --arb-roomtrack / --arb-windup / --arb-hitbox
[*]Space & special targets (v2.6.0): retreats from the wall band before a crowd squeezes it shut, resists edge drift, approaches bosses/elites, spawner eggs and cursed/evolved targets when safe, prices item crates as items and loot aliens as worth a detour
[*]DLC-aware (v2.4.0): engages cursed enemies (Abyssal Terrors) and evolved meca/mutant enemies (Primal Dread) by default, and walks over Primal Dread evolution consumables. Signed --arb-curse / --arb-evolved values tune the stance (negative = avoid).
[*]Behaviour priors are inferred from the build at runtime (HP/armor/dodge, lifesteal, "fire while moving", structures, economy) instead of a per-character table
[*]No shop or upgrade script extensions are installed — decisions are structurally untouched
[/list]

[b]中文说明[/b]

角色在波次内自动走位、闪避、砍树、受伤吃果子、捡材料；[b]所有决策仍由你来做[/b]：升级三选一、商店购买/刷新/锁定、开箱/消耗品、点"下一波"、角色/武器/难度。

v2.8.0 高价值全覆盖 + 实时攻击 CD 同步：Boss/精英分开定价（50/30），物品箱 20、传奇箱 34、进化物品 20、掉落怪 12、树 7 按显式价值进入机会层（reward 索引 6 打 tag，取 max(原值, 表值)；治疗果子保持 food 价值）；fire_still 角色的 tap-move 改为“武器 ready 才停 1 帧”的实时 CD 同步。开关：--arb-cov / --arb-tapcd（=0 精确 v2.7.0）/ --arb-dpsref=2（实验性 killability）。
v2.7.0 统一机会规划：v2.6 的“赏金接近 + 物品承诺”合并为“价值 − 路线风险”机会层——Boss/精英 30、蛋 40、诅咒/进化 18 显式定价，按“走过去要吃多少伤害”决定值不值得；特殊目标可见半径 900/1400/1600px（按 --arb-agg），逃跑掉落怪按实测速度拦截。开关：--arb-opp（=0 精确 v2.6.1）/ --arb-agg（0/1/2；13 开关全 0 回 2.4.0）。
v2.6.1 贴身/碰撞修复：不再贴着怪打转——拥挤项改为追击投影；蓄力定身怪补上接触价；精英/Boss/DLC 非圆形碰撞体的接触距离不再低估。开关：--arb-roomtrack / --arb-windup / --arb-hitbox，全 0 可回退。
v2.5.0–2.6.0 规划/空间：合围前预判突围 + 高价值物品目标承诺；贴墙带撤离 + open-floor 势场；赏金接近特殊目标（Boss/精英、蛋、诅咒/进化）；物品箱按“一个物品”定价、掉落怪值得追。

v2.4.0 DLC 适配：默认主动交战诅咒怪（DLC1）和机械/异变进化怪（DLC2），并主动捡新 DLC 的进化物品；不想打的时候用负数开关（如 --arb-curse=-1）进入回避姿态。开关全 0 精确回到 2.3.0。

v2.3.0 策略升级：远程 build 保持射程边缘风筝而不是贴脸；静场会砍树、掉血会吃果子；2 步前瞻规划；受击后 2 秒临时提高警戒。所有新行为都有精确回退开关。

控制：Shift+Space 随时开关（默认开启，左上角 HUD 显示状态，开关会保存）。

本 Mod 只装了“走位”相关的两个最小扩展，不装任何商店/升级扩展；角色参数从实时 build 数据（血量/护甲/闪避、吸血、移动射击、结构物、经济等）自动推导。

已在 Brotato 1.2.0.1 单机实测（第 1 波）。联机未验证；游戏更新可能失效，退订即恢复原版。

致谢：走位 AI 来自开源项目 BOTato（MIT，作者 boardengineer / Pasha），许可文件随 zip 附带。
